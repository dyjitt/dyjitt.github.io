Privacy Policy: DJ Math Numbers Autopost

Effective date: November 21, 2026

What this app is

DJ Math Numbers Autopost is an internal tool run by the owner of the DJ Math Numbers YouTube channel. It is not offered to the public. Its only user is the channel owner.

Data it accesses

  • YouTube Data API (youtube.upload): uploads the channel's own videos and sets their title, description, tags, and privacy.
  • YouTube Data API (youtube.readonly): reads the channel's own channel ID and recent uploads.
  • YouTube Analytics API (yt-analytics.readonly): reads views, watch time, and average view duration for the channel's own videos.
  • Google Drive: reads the owner's video drafts and writes a posting log and daily reports to the owner's own Drive folder.

How data is used

Data is used only to post the channel's videos and to write a private daily report for the channel owner. The app does not access other users' data.

Sharing and sale

The app does not sell, rent, or share any data with third parties. It does not use data for advertising. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

OAuth credentials are stored as encrypted GitHub Actions secrets. Reports are stored in the owner's private Google Drive and as private workflow artifacts kept for 30 days. Analytics data is not stored elsewhere.

YouTube

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account permissions or Google security settings.
